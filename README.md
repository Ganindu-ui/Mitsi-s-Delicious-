# 🍽️ Mitsi's Delicacies by Arabian Vibes (Colombo 03)

A creative, modern React web application for **Mitsi's Delicacies by Arabian Vibes Restaurant & Cafe - Colombo 03**, featuring real-time menu data, prices, and dish details synchronized with their official [Uber Eats Store](https://www.ubereats.com/store/mitsis-delicacies-by-arabian-vibes-restaurant-and-cafe-colombo-03/qXPclYMTUc-Xzt2bRvPoPg).

---

## ✨ Features

- **Authentic Brand Identity**: Styled with Mitsi's signature magenta (`#d9258b`) and Arabian amber accents in a modern luxury dark mode.
- **Accurate Uber Eats Products & Prices**:
  - Classic Chicken Submarine 12" (LKR 2,150.00)
  - Gourmet Turkish-Serbian Lamb Chops (LKR 9,250.00)
  - Classic Alfredo Pasta (LKR 3,000.00)
  - Authentic Chicken & Beef Shawarmas (from LKR 2,750.00)
  - Turkish Chicken Shish Kebab (LKR 3,950.00)
  - Fresh Mezze & Hummus with Warm Tortilla Bread (LKR 2,150.00)
  - Signature European Berry Chocolate Delicacy Cakes & Basque Cheesecakes
- **Interactive Dish Customization Modal**: Choose sides (Tortilla bread vs Grilled potatoes vs Fries), add-on toppings, and special chef cooking notes with live total calculations.
- **Interactive Shopping Cart Drawer**:
  - Delivery vs Takeaway switcher
  - Dynamic free delivery progress tracker (Free delivery over LKR 5,000)
  - Promo code system (`MITSI10` for 10% OFF)
- **Dual Ordering Channels**:
  - 📲 **Direct WhatsApp Order Generator**: Formats items, customizations, and customer details into a ready-to-send WhatsApp chat to the kitchen.
  - 🟢 **Uber Eats Direct Store Integration**: One-click link to order via the official Uber Eats app.
- **Celebratory Checkout**: Confetti animation and order confirmation receipt modal.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla CSS (Custom design system, glassmorphism, responsive grid)
- **Icons**: Lucide React
- **Celebrations**: Canvas Confetti

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Ganindu-ui/Mitsi-s-Delicious-.git
cd Mitsi-s-Delicious-
```

### 2. Install dependencies & run development server
```bash
cd frontend
npm install
npm run dev
```

### 3. Build for production
```bash
npm run build
```
